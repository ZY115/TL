# Training task cards

These cards are examples of ordinary warehouse operating requirements — pickup,
inspection, delivery, charging, hazard avoidance — not a list of benchmark
operators. A representation designer may infer and document any reasonable
closed abstraction that covers them.

Audit tasks stay within the same operational vocabulary and the same semantic
scope, but may combine familiar requirements in unfamiliar ways. Every audit
task is a requirement a warehouse supervisor could plausibly give; none exists
only to be difficult.
